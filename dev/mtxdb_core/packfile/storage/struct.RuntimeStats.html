Expand description

Point-in-time snapshot of a store’s runtime counters and the persisted pool stats embedded alongside them — see PackfileStorage::stats.

All fields are relaxed reads of independent atomics (no shared snapshot lock), so a snapshot is a consistent-enough picture, not a single instant in time. The read-path counters (get_*) are only meaningful while PackfileStorage::set_stats_enabled was true.
