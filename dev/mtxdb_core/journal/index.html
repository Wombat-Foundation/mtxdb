Module journal 

Source
Expand description

Checksummed append-only journal primitives for durable group commits. Append-only, checksummed commit journal used by the packfile WAL path.

This module owns the journal’s disk framing and durability boundary. It also provides JournalCoordinator, which captures each sync caller’s target LSN and releases it only after a durable group covers that target.
