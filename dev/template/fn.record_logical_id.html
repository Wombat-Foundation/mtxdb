pub fn record_logical_id(digest: &Digest32) -> NodeId
Expand description

Derive the 128-bit record routing key from a full identity digest.

The full digest remains the authoritative identity when it is available; this fixed-width prefix is only the core index key. Keeping the truncation here prevents adapters from independently choosing different slices.

§Panics

Never in practice: Digest32 is exactly 32 bytes, so its first 16 bytes always fit NodeId.
