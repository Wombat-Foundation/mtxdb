pub fn frame_digest(
    policy: &FrameIdPolicy,
    algorithm: DigestAlgorithm,
    input: &FrameIdInput<'_>,
) -> Option<Digest32>
Expand description

Derive a frame’s 256-bit logical identity under policy.

Returns None when the policy’s input is unavailable — a missing pointer or canonical form, or no descriptor — or when the identity is FrameIdPolicy::ExternalCanonicalIdToCrosscheck or FrameIdPolicy::Key and must be supplied by the caller instead.
