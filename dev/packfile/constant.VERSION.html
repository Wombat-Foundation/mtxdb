Packfile format version byte following MAGIC in the header (see write_header/read_header).

Version 4: replaces the v3 shard_id/epoch header fields with a single pack_id: u64 — the pool-local monotonic identity for the shard. Adds features: u32. Filename changes from shard_{slot:04x}_{epoch:016x}.pack to shard_{pack_id:016x}.pack. Hard cutover: v3 files are rejected at open.
