pub fn read_delta_log_v3(path: &Path) -> Option<DeltaLogV3>
Expand description

Read and structurally validate a v3 delta log.

Unlike v2 the frame region is variable-length, so after the fixed batch header the reader decodes exactly frame_count self-describing frames and expects the trailer immediately after the last one — it never scans for magic inside a payload. A frame that fails to decode, a short frame region, or a bad batch CRC after at least one committed batch is treated as the end of the trustworthy prefix; the fingerprint gates in storage reject a log that has lost a later batch. Returns None for a missing file, a bad header, the wrong version, or a log with no complete committed batch.
