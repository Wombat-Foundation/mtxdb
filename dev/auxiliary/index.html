Module auxiliary

Expand description

Named application-owned lookup indexes sharing the normal packfile engine. Named auxiliary indexes for application-owned lookup tables.

Auxiliary indexes are logical stores, not additional packfile pools. They use the normal StorageEngine so callers do not create one directory or file per room, namespace, or index name.
