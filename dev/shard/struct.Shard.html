Expand description

A single global shard file shared across all collections.

Fields§

§slot: u16

Pool-local allocator slot (index into the open-shard table). Ephemeral, recycled on retire. Never shown to operators.

§pack_id: u64

Pool-local pack_id, distinct from the slot index. Ensures a reused slot never collides on-disk with a still-referenced older file at that slot.

§file: File

The open file handle backing this shard.

§path: PathBuf

Filesystem path to this shard’s file.
