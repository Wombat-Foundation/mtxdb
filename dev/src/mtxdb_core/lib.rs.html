1//! mtxdb: a write-once, content-addressed packfile storage engine for Matrix.
2//!
3//! Never mutate, never delete, never tombstone. Every node is
4//! content-addressed and append-only; garbage collection is a background
5//! repack that rewrites only reachable data in traversal order.
6//!
