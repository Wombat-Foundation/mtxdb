pub fn encode_state_group_record(instance: &StateGroupInstance) -> Vec<u8> ⓘ
Expand description

Encode an STGP\x01 instance record:

"STGP" (4)
version 0x01 (1)
resolver tag (1)
trust tag (1)
parent count (u16 BE)
parent instance ids (16 bytes each, sorted, deduplicated)
state LtHash digest (32)
STAT/HAMT root node id (16)

Parents are canonicalized so identical derivations encode identical bytes.

§Panics

Panics if the instance has more than u16::MAX parent ids, which cannot be reached by a bounded state-group derivation.
