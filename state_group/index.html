Matrix state-group instance identity and record layout. Matrix state-group instance identity (STGP namespace).

A state group is identified at two independent layers:

  • its content (the shared HAMT) is keyed by the state LtHash and deduplicates equal state sets;
  • a derivation (one instance per predecessor set + resulting state) is keyed by an STGP instance id and preserves the derivation DAG.

Instance ids are deterministic, so replaying the same derivation is idempotent and no counter or random allocator is needed. Equal LtHash values with different parents stay distinct.

An StateGroupInstance record carries its parent ids, the full state LtHash, the shared HAMT root id, and the StateGroupDerivation that produced it; the instance id derives from the parents, the LtHash, and that derivation (the root follows from the state content).

The derivation is part of the identity on purpose: the same parents and the same state reached through two different resolvers, or under two different trust claims, are two different claims about the room and must never share an id.
